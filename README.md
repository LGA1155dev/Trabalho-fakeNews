## 📖 Sobre o projeto

O **DESINFORMA — Fake News em Foco** é um projeto desenvolvido com a proposta de abordar o problema da desinformação na sociedade digital.

Em um cenário onde informações circulam rapidamente por redes sociais, aplicativos de mensagens e plataformas digitais, nem tudo aquilo que chega até nós é verdadeiro, confiável ou apresentado de maneira imparcial.

O projeto busca apresentar esse fenômeno de forma visual e interativa, explorando o conceito de fake news, suas causas, casos conhecidos, consequências e formas de identificar informações potencialmente falsas.

A proposta é transformar um tema social importante em uma experiência digital mais envolvente, utilizando recursos visuais, animações, navegação interativa e conteúdo informativo.

---

## 🎯 O problema

A disseminação de notícias falsas se tornou um dos grandes desafios da sociedade conectada.

A facilidade de compartilhar informações permite que conteúdos incorretos, manipulados ou descontextualizados alcancem milhares de pessoas em pouco tempo, podendo influenciar opiniões, decisões e comportamentos.

Entre os principais problemas relacionados à desinformação estão:

- 📢 Compartilhamento de informações sem verificação.
- 🧠 Manipulação da opinião pública.
- ⚠️ Dificuldade em diferenciar fatos de conteúdos falsos.
- 📱 Disseminação rápida por redes sociais e aplicativos de mensagens.
- 🔍 Falta de verificação de fontes.
- 🗞️ Uso de manchetes sensacionalistas para atrair atenção.
- 🌎 Impactos sociais, políticos e econômicos causados pela desinformação.

A desinformação não depende apenas da criação de uma notícia falsa. Ela também se fortalece quando as pessoas compartilham conteúdos sem verificar sua origem, contexto ou credibilidade.

## 💡 A solução proposta

O projeto DESINFORMA busca abordar o problema através de uma página web educativa e interativa, apresentando informações sobre fake news de maneira organizada e visualmente atrativa.

A experiência foi estruturada para conduzir o visitante por diferentes aspectos da desinformação, transformando a navegação em uma apresentação informativa.

Em vez de utilizar apenas textos tradicionais, o projeto combina conteúdo, elementos visuais, animações e interações para estimular o interesse e facilitar a compreensão do tema.

### 🧭 O que o projeto aborda?

- 📖 O que são fake news e desinformação.
- ⚙️ Fatores que contribuem para sua disseminação.
- 🗞️ Casos e exemplos de desinformação.
- ⚠️ Consequências sociais da circulação de informações falsas.
- 🛡️ Dicas para identificar e evitar o compartilhamento de notícias falsas.

## 🛡️ Como identificar fake news?

O projeto também apresenta uma abordagem educativa, incentivando o visitante a desenvolver hábitos mais responsáveis ao consumir e compartilhar informações.

Algumas práticas importantes incluem:

- 🔎 Verificar a fonte original da informação.
- 📅 Conferir a data da publicação.
- 📰 Procurar a mesma informação em outros veículos confiáveis.
- ⚠️ Desconfiar de títulos exagerados ou sensacionalistas.
- 🖼️ Verificar imagens e vídeos fora de contexto.
- 🚫 Evitar compartilhar conteúdos que não foram verificados.
- 🧠 Analisar a informação de maneira crítica antes de acreditar nela.

A responsabilidade digital começa quando entendemos que compartilhar uma informação também pode contribuir para sua disseminação.

## 🚀 Como executar localmente

Você pode executar o projeto em sua própria máquina para visualizar seu funcionamento ou realizar modificações.

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/LGA1155dev/Trabalho-fakeNews.git
```

### 2️⃣ Acesse a pasta

```bash
cd Trabalho-fakeNews
```

### 3️⃣ Execute o projeto

Como o projeto utiliza HTML, CSS e JavaScript no próprio arquivo HTML, você pode abrir o arquivo `index.html` diretamente no navegador.

Ou utilizar um servidor local com Python:

```bash
python3 -m http.server 8000
```

### 4️⃣ Acesse no navegador

```text
http://localhost:8000
```
